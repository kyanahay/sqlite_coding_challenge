# SQLite Coding Challenge

## Overview
This project answers four business questions using SQL on the provided `bais_sqlite_lab.db` database. The analysis covers customer spending, product category revenue, employee salaries, and customer loyalty.

---

## Files
- `challenge.sql` – SQL queries for all tasks  
- `INSIGHTS.md` – Key findings from the results  
- `bais_sqlite_lab.db` – Database used for analysis  

---

## Tools
- DB Browser for SQLite  

---

## How to Run
1. Open `bais_sqlite_lab.db` in DB Browser for SQLite  
2. Open `challenge.sql`  
3. Run each query to view results  

---

## Summary
- Top customers generate a large share of revenue  
- Electronics is the leading product category  
- Salary differences exist within departments  
- Gold customers are concentrated in specific cities
