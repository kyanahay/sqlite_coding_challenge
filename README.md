# SQL Sales Analysis

## Description
This project analyzes customer, sales, product, employee, and loyalty data using SQL. The goal is to answer business questions that help identify top customers, revenue-driving product categories, salary trends, and customer loyalty patterns.

This project demonstrates how SQL can be used to turn raw relational data into useful business insights.

## Business Questions Answered
1. Which customers have the highest lifetime spend?
2. Which product categories generate the most revenue?
3. Which employees earn above their department average?
4. Which cities have the most Gold-tier customers?
5. How is customer loyalty distributed across cities?

## Files
- `challenge.sql` – SQL queries used for the analysis
- `INSIGHTS.md` – Summary of key findings from the query results
- `bais_sqlite_lab.db` – SQLite database used for the project

## Tools Used
- SQLite
- DB Browser for SQLite

## Key Skills Demonstrated
- SQL joins
- Common table expressions (CTEs)
- Aggregate functions
- Grouping and filtering
- Conditional aggregation
- Sorting and limiting results
- Business insight development

## Summary of Findings
- A small group of top customers contributes significantly to total revenue.
- Electronics is the strongest revenue-generating category.
- Furniture performs as a strong secondary category.
- Grocery and Stationery contribute minimally to total revenue.
- Salary differences exist within departments, especially in Sales and IT.
- Gold-tier customers are concentrated in specific cities, with Tampa leading.

## How to Run
1. Open `bais_sqlite_lab.db` in DB Browser for SQLite.
2. Open the `challenge.sql` file.
3. Run each query to view the results.
4. Review `INSIGHTS.md` for the business interpretation of the outputs.
